About

mariflag is a versatile SVG generator that converts text sequences into a series of icons. While originally inspired by maritime signal flags, it also lets you provide your own custom SVG icons for each letter — encoding text into various visual forms, limited only by your imagination (and the available SVG icons, of course).

For example, you can create visualizations inspired by semaphore signals, or encode text into designs similar to Morse code or Braille — and more.

  • Single composed SVG out; ships ESM + CJS + types
  • Bring your own icons via customIcons
  • Horizontal or vertical layout with configurable spacing

Install & use

npm install @imikailoby/mariflag
import { generateSvg } from '@imikailoby/mariflag';

const svg = generateSvg('Hello', { orientation: 'horizontal', offset: 16 });

Full configuration and custom-icon docs are in the project README.
